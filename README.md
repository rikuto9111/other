
■ 概要

本アプリは、現在地周辺のラーメン店を地図上に表示し、訪問履歴を記録・分析できるiOSアプリです。
ユーザーのラーメン訪問データを蓄積し、「嗜好の可視化」「行動の振り返り」「レベル化（ゲーミフィケーション）」を実現します。

■  コンセプト
ラーメン体験のデータ化（食べ歩きログ）と訪問履歴による自己分析
ゲーミフィケーション(レベル・称号)による継続利用の促進

■ アプリの基本フロー
アプリ起動時(ContentView)
　→ 現在地周辺（半径1500m）のラーメン店を地図に表示
店舗タップ
　→ 店舗詳細（評価・距離・営業時間・経路など）を表示
訪問操作
　→ 訪問登録（自己評価・感想）＋経験値付与＋レベルアップ
各種機能へ遷移
　→ 検索 / 訪問リスト / 分析 / 診断 / ランキング
 
■ 主要機能
 ・マップ機能
現在地周辺のラーメン店表示
訪問済み店舗の可視化（チェックアイコン）
営業時間外は白黒アイコン表示

 ・店舗詳細
店名,Google評価 ,現在地からの距離・ルート
経路表示（Google Maps API）
営業時間,自己評価・感想

 ・訪問管理
訪問記録（評価・ジャンル・感想）
訪問回数管理
再訪機能 / 削除機能
レベル・経験値システム

 ・検索機能
非同期でキーワード検索 -> 検索結果から地図中心移動

 ・訪問マップ
訪問済み店舗のみ表示
行動履歴の可視化

 ・分析機能
ジャンル割合
平均評価
月別訪問回数
総訪問数・レベル

 ・診断機能
訪問履歴からラーメン嗜好を分析
ジャンル・エリア傾向をもとにタイプ診断

 ・ランキング機能
都道府県別ランキング
ジャンル別ランキング
自己評価ベースのランキング

■ 技術設計
 ・データ管理
VRamenDatabase：訪問履歴管理
RamenDatabase：検索結果・キャッシュ管理

 ・API最適化
Google Places APIの利用回数削減設計
半径100m以内はローカルキャッシュを使用
同一エリアの再検索を抑制

 ・状態設計
訪問状態管理（未訪問 / 訪問済み / 再訪）
営業時間によるUI変化
レベル・経験値システム

■ 工夫した点
地図UIと訪問履歴のリアルタイム連動
行動データのゲーミフィケーション化
APIコスト削減のためのキャッシュ設計
ユーザー行動の可視化（分析・ランキング）
